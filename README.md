# ✏️ Sketchmorphism

Every SaaS landing page in 2026 looks like it was generated by the same prompt: purple mesh gradients, 1px borders, and Inter font. It's sterile and boring.

**Sketchmorphism** is a React & Vanilla UI component library built on hand-drawn strokes, cross-hatch depth, and paper physics.

No heavy Canvas or WebGL runtime. Just native SVG filters (`feTurbulence` + `feDisplacementMap`) layered over semantic HTML.

[**→ Open Live Interactive Demo**](https://viditx.github.io/sketchmorphism/prototypes/full-website-demo.html) | [**Design Spec (DESIGN.md)**](./DESIGN.md) | [**Use Cases (USE_CASES.md)**](./USE_CASES.md)

---

## 💡 Why this exists

I wanted interfaces that feel like they were drawn in a notebook with a 0.5mm ballpoint pen, without breaking DOM accessibility or shipping a 500KB canvas runtime.

* **Strokes over borders:** Borders aren't mathematically straight 1px lines. They wobble slightly using SVG displacement filters.
* **Hatches over shadows:** No blurred CSS `box-shadow`. Elevation is rendered using pencil cross-hatching. When you click a button, it physically sinks 3px into the hatch.
* **3-pencil rule:** Everything is built using a disciplined physical palette—Desk (`#d7cfbc`), Warm Paper (`#f4efe3`), Charcoal Ink (`#2b2823`), Draft Blue (`#47658c`), and Revision Red (`#c2402a`).
* **Fast & Accessible:** Pure CSS + SVG filter primitives. Hardware-accelerated in Chromium and WebKit with standard semantic HTML.

## 🚀 Quickstart

### 1. Install via npm

```bash
npm install @sketchmorphism/react @sketchmorphism/core
```

### 2. Usage in React

```tsx
import React from 'react';
import { Button } from '@sketchmorphism/react';

export default function App() {
  return (
    <div style={{ background: '#f4efe3', minHeight: '100vh', padding: '40px' }}>
      <Button onClick={() => alert('Handcrafted!')}>
        Click Me ✏️
      </Button>
    </div>
  );
}
```

### 3. Usage in Vanilla HTML & CSS

```html
<!-- Inject the base styles -->
<link rel="stylesheet" href="https://unpkg.com/@sketchmorphism/core/dist/style.css">

<!-- Button with organic hatch depth -->
<button class="skm-btn">
  <span class="skm-btn__label">Handcrafted</span>
</button>
```

## 🤖 The AI Prompt Blueprint (Cursor & Claude Rules)

If you're using **Cursor**, **Claude**, or **v0**, you don't even need the npm package to generate Sketchmorphism UI from scratch. Add this to your `.cursorrules` or system prompt:

```markdown
### Sketchmorphism Design System Rules:
1. Palette: Desk (#d7cfbc), Paper (#f4efe3), Ink (#2b2823), Revision Red (#c2402a), Draft Blue (#47658c). Never use pure black (#000) or pure white (#fff).
2. Never use standard `box-shadow`. Use 45-degree SVG cross-hatch patterns for elevation and depth.
3. Apply asymmetrical border radii on cards: `border-radius: 255px 15px 225px 15px / 15px 225px 15px 255px;` to avoid perfect digital rectangles.
4. Button active states must translate (3px, 4px) diagonally so the button visually sinks into the cross-hatch shadow underneath.
5. Typography: Pair Fraunces (Headings), Schibsted Grotesk (Body), and Space Mono (Metadata/code).
```

## 📦 Monorepo Architecture

* **`packages/core`**: Core SVG filter definitions (`feTurbulence`, `feDisplacementMap`), vanilla CSS variables, and design tokens.
* **`packages/react`**: React components (`Button`, `Input`, `Checkbox`, `Card`).
* **`packages/icons`**: Hand-drawn animated SVG icon suite.
* **`apps/docs`**: Documentation site and live prototype gallery.
